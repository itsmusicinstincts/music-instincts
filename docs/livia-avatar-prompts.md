# Livia AI Avatar — Design Ideas & Generation Prompts

> Use this with image tools (Midjourney, Flux, Ideogram) and video tools (Runway, Kling, Luma, Pika).  
> **Lock one base look first**, then only change how many mini-emoticons sit inside the mega-emoticon — never redesign the body.

## A) Character brief (decide once)

### Who Livia is
- A soft, friendly **virtual AI** “living” in a Pasir Ris condo — curious neighbour, not a weapon robot.
- Starts **emotionally incomplete**; learns Navras one by one.
- Comic: earnest, literal, head-tilt when confused.

### Recommended look (pick one lane)

| Lane | Description | Best for |
|------|-------------|----------|
| **1 — Soft hologram** | Semi-transparent humanoid glow, silver-blue light, faint circuit freckles | Stage projection, ethereal |
| **2 — Condo companion** | More solid, sleek white/silver “skin”, soft LED eyes, casual jacket silhouette | Relatable, comedic acting |
| **3 — Mega-emoticon HUD** | Livia holds / stands beside a large empty emoticon shell that fills with 9 mini-emoticons | Clearest “learning emotions” readout + comedy |

**Suggestion:** Lane **3** for storytelling clarity + Lane **1** glow for beauty.

## B) Emotion build-up — Mega-emoticon system

### The idea
1. Start: a big **empty grey emoticon outline** (circle face shell) next to Livia — no minis inside.
2. Each rasa: a **mini-emoticon** (colour + expression) appears, bounces, and **slots into** the big shell.
3. Layout: **3×3 grid inside the big face** (cleanest for stage) OR minis orbit then settle.
4. Finale: mega-emoticon is **full** — outer face can become a big “WOW / all feelings” smile while all 9 bounce inside.
5. Twist: outer face still complete, but **minis freeze / go grey / stop bouncing**.

## C) Master consistency tricks

1. Generate **1 hero reference image** → reuse as character reference every time.
2. Keep Livia’s body identical; only change **how many minis are inside the mega shell**.
3. Same camera: `medium shot, eye level, soft cinematic lighting`.
4. Same negative prompt every time.
5. **Pro tip for stage:** design mega + minis as **motion graphics** (CapCut / AE) over a locked Livia plate — emoji consistency is easier than regenerating AI faces each time.

## G) Workflow (practical)

1. Lock **Livia hero** (body only).
2. Design **mega shell + 9 minis** as a clean graphic set (Canva / AE / CapCut often cleaner than pure AI for emoji).
3. Composite: Livia plate + emoticon HUD layer for every rasa state.
4. Animate unlock: mini flies in → snap → bounce once.
5. Finale: all bounce; twist: freeze + grey.

### Why hybrid (AI body + graphic emoticons) wins
- Emoticons stay **identical** every show.
- Readable from the back row.
- Faster than regenerating “petals/faces” that drift.
